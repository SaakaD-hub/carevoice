# Code of Conduct

We're building something meant to help vulnerable people, and we expect the same care in how we treat each other.

**Expected:**
- Be respectful and patient, especially with people newer to the codebase.
- Critique code and ideas, not people.
- Give credit where it's due.
- Assume good intent, and ask when something is unclear.

**Not tolerated:**
- Harassment, insults or discriminatory language of any kind.
- Sharing anyone's private information without permission.
- Committing real patient data or deliberately exposing secrets.

**Reporting:** contact the project owner, @SaakaD-hub, privately. Reports are handled confidentially. People who break these rules may be removed from the project.

This code is based on the principles of the [Contributor Covenant](https://www.contributor-covenant.org).
